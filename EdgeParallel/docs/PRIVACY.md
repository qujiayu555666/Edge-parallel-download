# 权限与隐私

## Edge 扩展权限

| 权限 | 用途 |
| --- | --- |
| `downloads` | 查看任务信息，暂停和恢复原任务，建立加速任务，取消被替换的任务，完成后移除其取消记录。 |
| `webRequest`、HTTP/HTTPS 网站访问 | 观察请求方式、响应大小、文件版本及文件名，并识别带 Cookie 或认证头的请求以跳过自动接管。 |
| `nativeMessaging` | 由 Edge 启动已安装的本地下载助手并与其通信。 |
| `storage` | 保存设置和当前浏览器会话中的任务恢复信息。 |

扩展不注入网页脚本，不读取网页正文。它会观察 HTTP/HTTPS 请求元数据，用来将浏览器下载与原请求关联；无法唯一关联时保留原生下载。

## 数据如何使用

- Cookie、Authorization 等认证头不转发给本地助手。检测到这些头的浏览器下载不自动接管。
- 下载 URL、文件名、大小及版本标识只用于下载、状态显示与当前会话的任务恢复。URL 自身可能带有访问令牌，因此请勿公开包含私有链接的截图或诊断内容。
- 不接入统计或广告服务，不向项目作者上传下载记录。
- 文件请求发往原文件服务器及其重定向目标。本地组件通过随机端口向 Edge 提供数据，只监听 `127.0.0.1`；每个任务使用 256 位随机令牌。
- 已完成文件由 Edge 写入默认下载目录。本地助手不遍历下载目录寻找随机临时文件。

设置保存在扩展的本地存储；任务恢复信息保存在浏览器会话存储。卸载扩展后，相关扩展存储由 Edge 管理。卸载助手不会删除已下载文件。

## 安装对系统的修改

图形安装器将组件安装到当前用户的 `%LOCALAPPDATA%\Programs\EdgeParallel`，并注册当前用户的 Native Messaging 主机：

`HKCU\Software\Microsoft\Edge\NativeMessagingHosts\com.edgeparallel.bridge`

主机清单只允许扩展 ID `jcpnknmnbonffkcmnficeijhojknegbm` 调用助手。安装器另注册当前用户的 Windows 应用卸载入口。不添加开机启动项、系统服务或防火墙规则。

安装向导提供打开扩展管理页和复制路径的操作；用户自行启用开发人员模式并加载扩展。日常下载不会自动打开面板或独立下载窗口。

## 浏览器安全检查的边界

自动接管要求原任务与新任务均处于 Edge 报告的安全状态。扩展不会接受危险下载或绕过 Edge 警告。

加速任务经本地地址交付，因此 Edge 下载记录中的来源会显示本地地址，无法完整保留原网站的来源信誉检查语义。没有来源提供的可信散列时，组件只验证分段响应、字节数及文件版本，不声称验证发布者身份或文件真伪。
